# 📊 Bond Portfolio Risk Analysis (Convexity Sensitivity AI Agent)

## Project Overview

This project analyzes a bond investment portfolio using Microsoft Power BI. It focuses on portfolio performance, yield curve analysis, duration, convexity, and Monte Carlo simulation to assess interest rate risk under different market scenarios.

The project demonstrates end-to-end Business Intelligence development, including data transformation, data modeling, DAX calculations, KPI creation, and interactive dashboard design.

---

## Business Objectives

- Analyze bond portfolio performance.
- Evaluate interest rate risk using duration and convexity.
- Study the yield curve and forward rates.
- Simulate portfolio performance using Monte Carlo scenarios.
- Generate business insights through interactive dashboards.

## Dashboard Pages

### 1. Executive Dashboard

Provides a high-level overview of the portfolio including:

- Total Portfolio Value
- Total Bonds
- Average Yield
- Average Duration
- Average Convexity
- Sector-wise Portfolio Distribution
- Issuer-wise Portfolio Distribution

---

### 2. Yield Curve Analysis

Analyzes interest rate behavior using:

- Average Yield Curve
- Zero Rate Curve
- Forward Rate Curve
- Discount Factor Analysis

---

### 3. Monte Carlo Risk Analysis

Simulates multiple market scenarios to evaluate portfolio risk.

Includes:

- Average Total P&L
- Average Duration Effect
- Average Convexity Effect
- Average VaR Contribution
- Total P&L by Scenario
- Duration Effect by Scenario
- Convexity Effect by Scenario
- VaR Contribution by Scenario
